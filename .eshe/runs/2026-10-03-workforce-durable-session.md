# Workforce durable OTP, admission and proof readback

Plane: workforce authentication in the existing ZITADEL Login. Authorized actors
are currently eligible invited staff with a real verified provider email and an
exact registered client. Commercial users, absent-policy actors, expired or
revoked sessions and arbitrary actor claims are denied. Login owns orchestration
and current admission; ZITADEL owns codes, credential verification and provider
sessions. Identity owns canonical staff, invitations and capabilities. No new
money, product or identity truth is introduced.

This server-only slice preserves all existing dirty presentation/locales/brand
work. No UI changes or new copy are included; visible integration requires the
parent-owned Tier B evidence, French/English accessible light-only flows and real
browser proof. State progresses through durable quota reservation, provider
session, delivery, verification and limited admission, or retirement. SQL logout
epochs and revocation work are committed before provider deletion. Lost provider
results read exact metadata/factors without repeating effects. Fresh action
assertions are persisted before provider checks; identical accepted completion
readback returns the original 60-second receipt without extending it.

The private current-admission receiver uses a separate purpose credential and
exact issuer/subject/base-session/client tuple. Identity independently consults
it when issuing and consuming workforce proof. Native restricted/privileged
OIDC clients have exhaustive server-owned policy; the registry grants no console
action or direct-API permission. OTP readiness remains off until native role/client
and real actor qualification.

Proof: full current Login unit suite 82 suites/997 tests passed; eight isolated
real PostgreSQL tests passed, including concurrent quota/attempt reservations,
resend retirement, immutable passkey attempts, idle/absolute expiry and immediate
logout readback. The actual migration runner applied once and verified checksum
on retry in an owned disposable database. Production TypeScript passed. Pinned
ZITADEL v4.15.3 Session metadata/factor atomicity was inspected. Homelab workers
are unavailable due untolerated taints; the authorized local fallback was used.
No provider mutation, push, deployment or real staff proof is claimed. Dedicated
DB/runtime grants, packaged migration, private service boundary, SMTP, backup
restore, client/native RBAC, BFF logout and real authorized actors remain gates.
