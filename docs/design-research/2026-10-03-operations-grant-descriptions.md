# Operations access descriptions — Tier C

The authorized extension adds the three already owner-governed Operations grant
actions to the existing passkey ceremony. Operations owns current reviewers,
target eligibility consumption, resource scope and independent decision state;
Login verifies an action-bound provider passkey. A grant target, ordinary staff
member, commercial account or missing owner policy is not a reviewer. Verification
does not itself grant access.

Before presentation edits, the actual incumbent component was rendered on an
isolated loopback page and its accessibility tree/screenshot inspected. It uses
the established light C3 frame, one explicit native-prompt button, cancel,
truthful expiry and a quiet return path. The inherited material extension
research is in 2026-10-03-operations-passkey.md; no visual or interaction direction
changes here. The only visible addition is exact English/French review, approve
and revoke access descriptions. Do not show Person IDs, policy hashes, credentials
or internal authorization mechanics. No grants or real provider calls exist in
the preview.
