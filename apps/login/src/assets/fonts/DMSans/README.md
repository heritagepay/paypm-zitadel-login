# DM Sans

Bundled from PayPM's canonical Merchant mobile assets, derived from the Latin Extended static 400/500/600 faces of `@fontsource-variable/dm-sans@5.3.0`. SIL Open Font License is included in `OFL.txt`.

Hosted sign-in uses local files rather than fetching a second font family from Google. Explicit ZITADEL organization font branding remains supported by ThemeWrapper; this is the shared PayPM default, not another identity source.
