# Hosted-login control source preview

Run from `apps/login` with Bun and an already installed compatible Chromium:

```sh
PLAYWRIGHT_MODULE=/path/to/existing/playwright/index.mjs LOGIN_CONTROL_OUTPUT=/outside/checkout bun tests/browser/control-affordance.tsx
```

The harness compiles the actual SCSS/Tailwind configuration and SSR renders the
current shared Button, Spinner, PayPM brand, Copy, IdP adapter and native method cards. Locale/session/MFA Skip anatomy projects
existing owner classes with synthetic account labels. It mounts no authentication
route, provider handler, account, cookie write or credential request, and blocks
all external traffic. This is source-preview evidence, not authenticated route or
actor proof.

Sixteen FR/EN states with496 control measurements cover320/390/768/1280px and100/200% visible text. Checks require
44px hit areas, wrapped labels, no page overflow,3:1 enabled secondary/locale
boundaries and focus, opaque pending/disabled states, a static contrasting spinner
arc under reduced motion, and immediate inset feedback on actual native-control
padding. Available method cards retain keyboard focus and configured cards remain
opaque and non-actionable. Existing language/session/username/password and new
logout/copy/MFA component unit tests prove real callback guards and recovery
separately. A component-owned server-action adapter awaits the existing logout
callback and returns only a plain boolean confirmation; both session controls
require explicit success. Cookie policy and provider APIs remain unchanged.
